Notes: (1) each MLlib model is a single deterministic run (seed 42); the ranking among MLlib models is descriptive. The best MLlib model per horizon is selected after seeing its test RMSE, which makes M1 conservative for the GNN. (2) ILI_trend = ILI_lag1 − ILI_lag2 exactly, so the linear features are collinear: MLlib's Cholesky solver reports a singular matrix and falls back to L-BFGS, and individual linear coefficients (e.g. ±108 for the lag-only model) are not identifiable — predictions are unaffected, but the coefficients must not be interpreted. Tree importances are unaffected. (3) Earlier results compared the GNN with a fixed-setting GBT (50 trees, depth 5, lags only); against these tuned MLlib models the GNN is not significantly better at any horizon.
